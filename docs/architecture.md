# Arquitetura — Operational Intelligence Hub

> Documento vivo. Atualize a cada decisão técnica relevante.

## 1. Objetivo

Consolidação dos KPIs operacionais e de negócio em uma interface única.

## 2. Componentes

| Componente | Responsabilidade |
|---|---|
| index.html | Interface do hub (HTML, CSS e JavaScript) |
| API (FastAPI) | Consolida e expõe os indicadores das demais soluções |
| PostgreSQL | Histórico e séries temporais dos KPIs |
| n8n | Atualização periódica dos dados e alertas de negócio |
